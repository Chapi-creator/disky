Escaneo

Dos formas de escanear: Normal: recorre todo con tus permisos (sin UAC), pero las carpetas protegidas del sistema se cuentan como errores de lectura. Completo (admin): además lee el interior de esas carpetas protegidas (WinSxS, System Volume, etc.). Usa UAC solo si te faltan datos ahí.

El escaneo completo de una carpeta pide permisos de administrador (UAC) para leer también las carpetas protegidas del sistema; no muestra progreso. El de todas las unidades con admin pide un único UAC para todo el lote, va mostrando el progreso unidad a unidad y se puede cancelar (tarda unos segundos en detener la unidad en curso).
